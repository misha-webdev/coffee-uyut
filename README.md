# Кофейня «Уют» — демонстрационный сайт

Одностраничный адаптивный сайт кофейни: меню с категориями, демо-бронирование столика, стилизованная схема проезда и аккуратные анимации. Написан на чистых HTML, CSS и JavaScript, без фреймворков и сборки.

> **⚠️ Это демонстрационный проект для портфолио.**
> Кофейни «Уют» не существует. Адрес, телефон, почта, позиции меню с пометкой «Демо» и их цены вымышлены. Форма бронирования ничего не отправляет и не сохраняет.

**Демо:** https://misha-webdev.github.io/coffee-uyut/

## Возможности

- **Главный экран** — композиция из фото в форме арки, вращающаяся «печать», плавающая плашка, SVG-логотип.
- **Меню с категориями** — вкладки «Кофе / Авторские / Чай / Выпечка и десерты» с плавающей подложкой, счётчиками позиций и анимацией смены карточек. Управление стрелками, Home и End.
- **Демо-бронирование** — модальное окно на `<dialog>`: проверка имени, даты и времени (время строится по часам работы), счётчик гостей, понятные сообщения об ошибках. Закрывается кнопкой, клавишей Esc или кликом по фону; на телефоне выезжает «шторкой» снизу.
- **Схема проезда** — нарисована в SVG в фирменных цветах, с явной пометкой, что адрес вымышленный.
- **Анимации** — появление блоков при прокрутке, микровзаимодействия при наведении. Всё отключается, если в системе включено «Уменьшить движение».
- **Адаптивность** — проверено на ширинах 360, 390, 768, 1024, 1280 и 1440 px.

## Технологии

| Область | Что использовано |
|---|---|
| Разметка | Семантический HTML5, `<dialog>`, SVG-спрайт иконок, ARIA-разметка вкладок |
| Стили | CSS custom properties (дизайн-токены), Grid и Flexbox, `clamp()`, `aspect-ratio`, `@media (hover)` и `prefers-reduced-motion` |
| Скрипты | Vanilla JavaScript: `IntersectionObserver`, `ResizeObserver`, `matchMedia`, валидация формы |
| Шрифты | Playfair Display и Manrope (Google Fonts) |
| Фото | Бесплатные снимки с [Pexels](https://www.pexels.com/license/), источники — в [images/CREDITS.txt](images/CREDITS.txt) |

Сторонних библиотек нет.

## Доступность и производительность

- Контраст текста — не ниже 4.5:1 (WCAG AA), у полей формы — рамка с контрастом от 3:1.
- Полная работа с клавиатуры: ссылка «Перейти к содержимому», видимая рамка фокуса, фокус удерживается внутри окна бронирования и возвращается на кнопку после закрытия.
- У всех изображений есть `alt` и размеры `width`/`height`; фото ниже первого экрана и скрытых категорий меню загружаются лениво.
- Lighthouse пока не запускался — результаты будут добавлены после публикации.

## Запуск

Сборка и установка не нужны.

1. Скачайте репозиторий: **Code → Download ZIP** — или клонируйте его:
   ```bash
   git clone <адрес-репозитория>
   ```
2. Откройте `index.html` в браузере.

Для разработки удобно расширение **Live Server** для VS Code: страница обновляется после каждого сохранения.

## Публикация на GitHub Pages

1. Загрузите в репозиторий `index.html`, `style.css`, `script.js` и папки `images/` и `docs/`.
2. **Settings → Pages → Build and deployment:** источник **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–3 минуты сайт откроется по адресу вида `https://<имя-пользователя>.github.io/<репозиторий>/`.
4. Если адрес сайта изменится, обновите его в `index.html` (теги `canonical`, `og:url`, `og:image`) и в этом README.
